# ADC-payload-potency-benchmark
ADC Payload Potency Prediction: Leakage-Aware Benchmark

This repository contains the code and data supporting the MSc research project "Leakage-Aware Evaluation of Machine Learning Models for Antibody-Drug Conjugate Payload Potency Prediction" (UCL School of Pharmacy, MSc Pharmaceutics, 2025-2026).

The study re-evaluates three models (XGBoost, a reimplemented GNN based on the DumplingGNN architecture, and ADCNet) on a single shared, leakage-aware benchmark, and reports uncertainty estimation and applicability-domain analyses. The dataset is the curated ADC data released with ADCNet (Chen et al., 2025), itself derived from ADCdb.

Contents (File/Description)

fair_comparison.ipynb	

Analysis notebook: featurisation, shared split generation (random, drug-based, five-fold cross-validation, and maximum-Tanimoto-dissimilarity holdout), and XGBoost and reimplemented-GNN training and evaluation.

data.xlsx	

ADCNet source data (antibody-drug conjugates with payload and linker SMILES and activity labels).

t_data.xlsx	

ADCNet held-out test set (49 conjugates), same format as data.xlsx.

Dataset

The dataset is the curated ADC data released with ADCNet (Chen et al., 2025), derived from ADCdb (Shen et al., 2024). After removing three conjugates whose SMILES failed to parse, 432 conjugates spanning 70 unique payloads and 82 unique linkers were used for modelling. Payload and linker are each encoded as a 2048-bit Morgan fingerprint (radius 2) and concatenated into a 4096-dimensional feature vector.

Evaluation splits

Four partitioning schemes are generated and written to a single split-definition file so that all models are evaluated on identical partitions:

Random (stratified, 10 seeds) — leakage-permitting control, matching the original ADCNet evaluation setting
Drug-based (payload-disjoint, 10 seeds)
Five-fold cross-validation (payload-level stratified)
Maximum-Tanimoto-dissimilarity holdout — the 14 most structurally isolated payloads (26 conjugates)

Reproducibility

This work follows the FAIR principles (findability, accessibility, interoperability, and reusability). All figures in the report were produced from the values generated by this notebook.
